# Hisab Pro

Premium offline-first Android accounting app for daily personal and small-business bookkeeping in Saudi Arabia.

## Download Android APK

**Latest APK:** [Download Hisab-Pro.apk](https://github.com/rejoyanislam9009-lab/hisab-pro/releases/download/latest/Hisab-Pro.apk)

**Release page:** [Hisab Pro - Latest Release](https://github.com/rejoyanislam9009-lab/hisab-pro/releases/tag/latest)

> On Android, open this GitHub page in Chrome, then tap the APK link above. The APK is served directly by GitHub Releases.

## Current features
- SAR dashboard with income, expense and live balance
- Multiple cash/bank accounts
- Income and expense ledger with categories and notes
- Customer/supplier/person ledgers with receivable/payable tracking
- Reports and top expense categories
- CSV backup/share
- Offline SQLite storage
- Premium dashboard and custom wallet icon

Every push to main builds the APK and publishes the latest installable file to GitHub Releases.
